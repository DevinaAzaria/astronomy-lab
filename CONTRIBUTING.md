# Contributing

Astronomy Lab is first a student learning portfolio. Contributions should help Devina understand, verify, and explain the science—not merely add features.

For each scientific change:

1. State the question and assumptions.
2. Cite the physical relation or dataset in the documentation.
3. Add a known reference case as a test.
4. Explain units and input limits.
5. Record the author and reviewer roles accurately.

Use small pull requests with a clear explanation of what changed and why.
